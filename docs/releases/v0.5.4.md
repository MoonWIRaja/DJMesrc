## DJMesrc v0.5.4

This release removes the vinyl rotation toggle. Both platters now rotate automatically while their deck is playing, including when Windows has reduced-motion enabled. Paused or stopped decks keep the platter still.

### Downloads

- `DJMesrc_0.5.4_x64-setup.exe` - Windows setup installer.
- `DJMesrc_0.5.4_x64_en-US.msi` - Windows Installer package.
- `SHA256SUMS.txt` - SHA-256 digests for both installers.

See the [quick-start guide](https://github.com/MoonWIRaja/DJMesrc/blob/main/docs/quick-start.md) for deck, queue, crossfader and soundboard operation.
