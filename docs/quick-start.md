# DJMesrc quick start

This guide covers the usual setup for a small event. The app interface is in English.

## 1. Add your music

Use **ADD TRACK** under either deck. Choose one or more local audio files. Deck A and Deck B work independently; assign either deck to background music, event music or another role that fits the event.

## 2. Arrange the queue

The first row is the track that is loaded or playing. Drag rows to change the order. Select a queued track to play it immediately. Right-click a track for **PLAY NOW** and **REMOVE FROM QUEUE**. Removing the current track asks for confirmation and loads the next track when one is available.

With **LOOP** on, the current track repeats. With Loop off, the queue advances when a track ends and moves the completed track to the bottom.

## 3. Balance the decks

Use a deck's volume slider for its level. The center crossfader moves the mix between Deck A and Deck B. The decks are not assigned background or event roles by the app, so choose the arrangement that is easiest for the operator.

Pause keeps the current playback position. When both decks are playing, Stop fades the selected deck while the other keeps playing. A solo deck stops directly.

## 4. Trigger a sound effect

Choose **ADD SOUND** in the Sound FX area and select a short audio file. Each pad has its own volume and color. Triggering another pad while an effect is playing starts it too; the effects can overlap. Music is lowered during SFX playback and returns to its saved level when the final active effect ends. **STOP ALL** stops every playing sound effect.

## 5. Use the first-run tutorial and shortcuts

On first launch, choose **TUTORIAL** to try the main controls or **SKIP** to go straight to the desk. The first-launch choice appears once. Shortcuts can be assigned from **SHORTCUTS**. Press Escape while assigning to clear or cancel the selected shortcut. Duplicate keys are not accepted.

## File notes

DJMesrc stores the selected audio paths for session restoration; it does not copy music into a DJMesrc library. If a source file is moved or removed, use its **LOCATE FILE** action to reconnect it. Supported extensions include MP3, WAV, FLAC, OGG, AAC and M4A, subject to the actual encoding.
