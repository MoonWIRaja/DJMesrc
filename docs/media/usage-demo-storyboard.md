# DJMesrc usage demo

## Delivery

- Audience: event staff who do not use advanced DJ software.
- Format: 60-second silent screen capture of the exact DJMesrc window, 1280-pixel wide MP4, with English captions.
- Visual source: the actual DJMesrc v0.5.4 app controlled with CUA. Demo audio files are generated locally for this recording and are not part of the app or release.
- Audio: none. Captions carry the instructions so the clip is usable in README and on the website without relying on an audio device.

## Beat map

| Time | On-screen action | Caption |
| --- | --- | --- |
| 00:00-00:05 | Show both decks playing, their queues and the soundboard. | Two decks and Sound FX stay in one workspace. |
| 00:05-00:14 | Move the crossfader toward each deck and return it to center. | Bring either source forward with the crossfader. |
| 00:14-00:24 | Adjust one deck's level, then show the independent queue rows. | Each deck has its own volume and queue. |
| 00:24-00:35 | Select the next queued track to play it now. Show the queue reorder. | Select a queued track to play it now. The queue follows. |
| 00:35-00:47 | Trigger the short sound effect while both tracks play. | Music lowers while the sound effect plays. |
| 00:47-00:55 | Stop one deck while the other keeps playing; let the fade finish. | Stop fades the selected deck while the other keeps playing. |
| 00:55-01:00 | Resume the deck and return to the two-deck overview. | DJMesrc keeps event audio simple for the whole team. |

The published recording and captions are stored in `apps/website/public/media/`.
